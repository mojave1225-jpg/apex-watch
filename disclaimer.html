02

◈DOOMSDAY INDEX™ とは

DOOMSDAY INDEX™（以下「DI」）は、APEX WATCHが独自に定義した複合リスク指標です。世界の複数のドメインから取得したデータを正規化・重み付けして合算し、0〜100のスコアとして算出します。

DIは「世界崩壊の確率」を示すものではありません。観測可能な複数のシグナルが、過去の平均からどの程度乖離しているかを示す相対的な緊張指標です。スコアが高いほど、複数のリスクシグナルが同時に高まっていることを意味します。

DIは5分間隔でAPIデータを再取得・再計算します。未取得のカテゴリは直前値を使用し、全カテゴリが未取得の場合は「計算中」を表示します。

◈サイバー脅威コンポーネント詳説

サイバー脅威スコアはabuse.ch Feodo Trackerが公開するボットネットC2（コマンド&コントロール）サーバーの実データをもとに算出します。

◈ Feodo Trackerは、Emotet・QakBot・TrickBot・LockBit等の主要マルウェアファミリーのC2インフラを追跡する非営利セキュリティ研究プロジェクトです。本データは認証不要で公開されており、30分ごとに更新されます。

スコア算出ロジック：

① 活動中（status: online）のC2サーバー総数を過去90日ローリング平均と比較
② マルウェアファミリーをDDoS / Ransomware / Malware / Phishing / Exploit に分類
③ ランサムウェア系（QakBot, LockBit等）が多い場合は危険度スコアを1.3倍に増幅
④ 攻撃源の上位国がCN/RU/KP/IR に集中している場合は追加スコア

可視化とデータの関係：

マップ上の攻撃弧は実際のC2インフラの国別分布から重み付けされた確率的シミュレーションです。個々の弧が「今この瞬間の攻撃」を1対1で再現するものではありませんが、どの国のインフラが脅威の中心にあるかを現実のデータで反映しています。

▶算出アルゴリズム

各カテゴリスコアは、対象指標の現在値を過去90日間のローリング平均と比較し、偏差を0〜100に正規化します。その後、重み付け平均を計算します。

正規化スコア（各カテゴリ）

Si = clamp( (Vi − μ90) / σ90 × k, 0, 100 )

Vi = 現在値 　μ90 = 90日ローリング平均 　σ90 = 90日標準偏差
k = カテゴリ別スケーリング定数（軍事: 12, 資産: 15, 地政: 10, サイバー: 11, 海運: 8, 居住権: 20, NEO: 25）

DOOMSDAY INDEX™ 最終スコア（v2.7.0）

DI = 0.28×Smil + 0.20×Sasset + 0.18×Sgeo + 0.15×Scyber
     + 0.12×Sship + 0.04×Sres + 0.03×Sneo

算出は5分間隔。APIデータが未取得のカテゴリは直前値を使用。全カテゴリ未取得の場合は「計算中」を表示。

計算例（例: 緊張期）

Smil=72, Sasset=60, Sgeo=55, Scyber=48, Sship=30, Sres=40, Sneo=8
DI = 0.28×72 + 0.20×60 + 0.18×55 + 0.15×48 + 0.12×30 + 0.04×40 + 0.03×8
   = 20.2 + 12.0 + 9.9 + 7.2 + 3.6 + 1.6 + 0.2 = 54.7（CAUTION ゾーン）

▸既知のバイアスと限界

⚡ 以下のバイアスは本指標に構造的に内在します。利用者はこれらを理解した上でDIを参照してください。
  • ADS-B未搭載機：軍用機の一部はADS-Bトランスポンダを停止または未搭載で飛行します。検出数が少ない＝活動が少ないとは限りません。逆に検出増加は意図的な「見せる示威行動」の可能性もあります。
  • C2サーバー所在地≠攻撃者の国籍：Feodo TrackerはC2インフラのホスティング場所を示します。米国・ドイツのAWS/GCPインスタンスが多く登場するのは、脅威アクターがこれらのクラウド事業者を悪用するためです。サイバー攻撃の発信源国ではない点に注意が必要です。
  • BDIの平時バイアス：90日ローリング平均は、長期的な高緊張期が続く場合に感度が低下します。構造的な高騰期においてスコアが過小評価される性質があります。
  • 居住権データの年次遅延：Henley & Partners・Arton Capitalのデータは年次報告が多く、直近のラッシュを反映できません。このカテゴリの重みは4%に抑えています。
  • DEFCONおよびFPCON推定値：本サイトの推定値は公式機関による発表ではありません。公式の安全保障ステータスと異なる場合があります。
  • スケーリング定数（k値）の主観性：DIのkパラメータおよび重み付けは本サイトが経験的に設定したものであり、学術的な検証を受けたものではありません。
  • NEOデータの不確実性：新しい小惑星の発見・軌道改定により数値は随時変化します。LD距離の精度は観測データの質に依存します。
